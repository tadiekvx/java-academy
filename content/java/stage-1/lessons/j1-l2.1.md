## Explanation

So far you've printed text. Programs work with much more than text: ages, prices, temperatures, answers to yes/no questions. Each piece of information is a **value**, and every value in Java has a **type** that says what kind of value it is.

### Five types to start with

| Type | What it holds | Examples in code |
|---|---|---|
| `int` | Whole numbers, positive or negative | `42`, `0`, `-7` |
| `double` | Numbers with a decimal point | `3.14`, `0.5`, `-2.0` |
| `boolean` | Yes/no: exactly one of two values | `true`, `false` |
| `char` | A single character, in **single** quotes | `'A'`, `'7'`, `'?'` |
| `String` | Text of any length, in **double** quotes | `"Hello"`, `"A"`, `""` |

A value written directly in your code, like `42` or `"Hello"`, is called a **literal**.

A few details matter:

- **`int` vs `double`**: `7` is an `int`, but `7.0` is a `double`, because the decimal point makes it one. An `int` can hold numbers up to about 2.1 billion either way, which is plenty for now.
- **`char` vs `String`**: `'A'` (single quotes) is a `char`, exactly one character. `"A"` (double quotes) is a `String` that happens to be one character long. Java treats them as different types.
- **`String` has a capital S**, unlike the other four. You'll find out why in Stage 2.
- **`true` and `false`** are written without quotes. `"true"` in quotes is a `String`, not a `boolean`.

### Printing values

`IO.println` can print a value of any of these types:

```java runnable
void main() {
    IO.println(42);
    IO.println(3.14);
    IO.println(true);
    IO.println('J');
    IO.println("Java");
}
```

Two things to notice when you print a `double`:

- A `double` **always shows a decimal point**: `IO.println(7.0)` prints `7.0`, not `7`.
- Unneeded zeros at the end disappear: `IO.println(1.50)` prints `1.5`.

### Expressions have types too

`3 + 4` is an **expression**: a calculation that produces a value. Its type follows from the values in it:

- `3 + 4` is `int + int`, so the result is the `int` `7`.
- `3 + 4.0` mixes an `int` and a `double`. Java converts the `int` to a `double` first, so the result is the `double` `7.0`.

You'll explore arithmetic properly in [Arithmetic](j1-l2.3).

### Types are checked when compiling

Java checks types before your program runs. If a value's type doesn't fit where you've put it, you get a compiler error instead of a wrong answer later. You'll see two of these messages in the exercises:

- `incompatible types: possible lossy conversion from double to int`: you tried to put a decimal where only a whole number fits, which would lose the part after the point.
- `incompatible types: String cannot be converted to boolean`: you wrote `"true"` (text) where `true` (a yes/no value) was needed.

### How exercises with a method header work

From now on, many exercises give you a **method header** to complete, like this:

```java
int secondsIn(int minutes) {
    return 0; // replace 0 with your expression
}
```

Read the first line as a sentence:

- `secondsIn` is the method's **name**.
- `(int minutes)`: you're **given** a whole number, called `minutes`.
- The `int` at the very start: you must **produce** a whole number.
- `return` hands your result back. Whatever follows `return` is the answer.

The tests run your method many times with different values for `minutes` (1, 2, 60, …) and check each result. So your expression must work for **any** value, not just one example: `return minutes * 60;` (the `*` means multiply), not `return 60;`.

Each starter also has a `void main()` that tries your method once, so you can press **Run** and see the result. You'll learn to write method headers yourself in Module 5.

## Worked examples

### Example 1: choosing types

*Task: a gym's app stores information about a member. Choose a type for each piece.*

**Step 1 — Ask: is it a number?** Age in years: a whole number, so `int`. Height in metres, like `1.75`: has a decimal point, so `double`.

**Step 2 — Ask: is it yes or no?** "Has paid this month": `boolean`.

**Step 3 — Ask: is it one character, or text?** Membership grade (`'A'`, `'B'` or `'C'`): a single character, so `char`. Name: text, so `String`.

| Information | Value | Type |
|---|---|---|
| Age | `34` | `int` |
| Height | `1.75` | `double` |
| Has paid | `true` | `boolean` |
| Grade | `'B'` | `char` |
| Name | `"Priya"` | `String` |

**Step 4 — Watch for tricky cases.** A phone number is made of digits, but you never do arithmetic on it, and it can start with 0 (`07700 900123`). Store it as a `String`.

### Example 2: your first method frame

*Task: complete `int secondsIn(int minutes)` so it gives the number of seconds in any number of minutes.*

**Step 1 — Read the header.** Given: a whole number `minutes`. Produce: a whole number.

**Step 2 — Work out one case by hand.** 2 minutes is 2 × 60 = 120 seconds.

**Step 3 — Replace the specific number with the name.** For any number of minutes, it's `minutes * 60`.

**Step 4 — Return it, then run `main` to check one value.**

```java runnable
int secondsIn(int minutes) {
    return minutes * 60;
}

void main() {
    IO.println(secondsIn(2));
}
```

This prints `120`.

## Where this is used

- **Forms and databases.** Every field in a sign-up form or a spreadsheet column has a type. A date-of-birth field that accepts any text leads to bad data; typed fields catch it straight away.
- **Money.** Shops and banks think hard about which number type to use for money, because decimals can be stored inexactly. You'll see why in [Arithmetic](j1-l2.3).
- **Error prevention.** Java's type checks catch many mistakes before the program even runs, which is one reason it's popular for large, long-lived systems.

## Common mistakes

### Putting a decimal into an `int`

`int price = 4.99;` doesn't round the price. It doesn't compile, because the `.99` would be lost. If a value can have a fractional part, use `double`.

### Quotes around `true`, `false` and numbers

`"true"` and `"42"` are text. They look right when printed, but you can't do arithmetic with `"42"`, and `"true"` can't be used where a `boolean` is needed.

### Mixing up single and double quotes

`'Hello'` doesn't compile, because single quotes hold exactly one character. Text uses double quotes: `"Hello"`.
