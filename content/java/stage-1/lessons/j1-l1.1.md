## Before you start

You don't need to know anything about programming. You don't need to install anything either: every program in this course runs right here in your browser.

You will need to type carefully, though. Computers do exactly what you write, not what you meant, so a single missing quote mark can stop a program from working. That's normal. The next lesson is all about what to do when it happens.

## Explanation

### What a program is

A **program** is a list of instructions for a computer, written in a language it understands. Each instruction is called a **statement**. When you run a program, the computer carries out the statements **one at a time, from top to bottom**.

Here is a complete Java program. Press **Run**.

```java runnable
void main() {
    IO.println("Hello, world!");
}
```

It prints `Hello, world!`. Every program you write in this stage has the same shape:

- `void main() {` marks where the program starts. Java looks for `main` and runs whatever is inside it.
- The **braces** `{` and `}` mark the start and end of `main`. Everything between them belongs to it.
- `IO.println("Hello, world!");` is a statement. It tells Java to print a line of text.
- The text inside **double quotes** is printed exactly as written. Text like this is called a **string**.
- The **semicolon** `;` marks the end of the statement, the way a full stop ends a sentence.

The statements inside `main` are indented by four spaces. Java doesn't need that, but people do: indenting shows at a glance what's inside the braces.

### Running a program: two steps

When you press Run, two things happen:

1. **Compiling.** Java reads your whole program and checks that it's written correctly. If anything is wrong, it stops and tells you, and nothing runs.
2. **Running.** If the check passes, Java carries out your statements, top to bottom.

You'll see why this matters in the next lesson.

### Printing: `println` and `print`

`IO.println` prints its text and then **moves to a new line**, so whatever is printed next starts on the line below. (`println` is short for "print line". That's a lower-case L, not a capital I.)

`IO.print` prints its text and **stays on the same line**.

```java runnable
void main() {
    IO.print("Ready, ");
    IO.print("steady, ");
    IO.println("go!");
    IO.println("Second line");
}
```

This prints `Ready, steady, go!` on one line, then `Second line` on the next. `IO.println()` with nothing inside the brackets prints an empty line, which is handy for spacing out your output.

### Comments

Anything after `//` on a line is a **comment**. Java ignores it completely; it's a note for people reading the code. For a longer note, start with `/*` and end with `*/`:

```java runnable
void main() {
    // This line is ignored, even if it looks like code: IO.println("hidden");
    IO.println("Only this is printed");
    /* A longer comment
       can run over several lines. */
}
```

Good comments explain **why** code does something, not what it does: the code already says what.

### Capital letters matter

Java is **case-sensitive**: `IO`, `io` and `Io` are three different names, and only `IO` is the one that prints. The same goes for `println`. You'll see what Java says when you get one wrong in the next lesson.

## Worked examples

### Example 1: a three-line message

*Task: print a short welcome message on three lines.*

**Step 1 — Decide what the output should look like, line by line.** Write it down before you write any code:

```
Welcome to the Java Academy
Lesson 1: Your first program
Let's go!
```

**Step 2 — One `IO.println` per line, in the same order.** Statements run top to bottom, so the order of the statements is the order of the lines.

**Step 3 — Copy each line's text exactly into double quotes.**

```java runnable
void main() {
    IO.println("Welcome to the Java Academy");
    IO.println("Lesson 1: Your first program");
    IO.println("Let's go!");
}
```

**Step 4 — Run it and compare with Step 1.** Check capital letters, spaces and punctuation. They all count.

### Example 2: building one line from pieces

*Task: print `3... 2... 1... Lift off!` on a single line, from four separate statements.*

**Step 1 — Notice it's one line of output.** Everything before the last piece must stay on the same line, so use `IO.print` for those.

**Step 2 — Finish the line with `IO.println`,** so anything printed afterwards starts on a fresh line.

**Step 3 — Put the spaces inside the quotes.** `IO.print` adds nothing between pieces, not even a space.

```java runnable
void main() {
    IO.print("3... ");
    IO.print("2... ");
    IO.print("1... ");
    IO.println("Lift off!");
}
```

Try removing the space after `1...` and running it again.

## Where this is used

- **Command-line tools.** Tools programmers use every day, like `git` and `java` itself, talk to you entirely by printing lines of text.
- **Logs.** Servers print a line for every important thing they do, such as `Started web server on port 8080`, so engineers can find out what happened when something goes wrong.
- **Checking your own work.** Printing a value is the quickest way to see what your program is doing. You'll use it constantly while you learn, and long after.

## Common mistakes

### Forgetting the double quotes

`IO.println(Hello);` doesn't print `Hello`. Without quotes, Java thinks `Hello` is the name of something in your program, can't find it, and reports an error. Text to print always goes inside `"double quotes"`.

### Mixing up `print` and `println`

If your output is all squashed onto one line, you've probably used `IO.print` where you meant `IO.println`. If it's spread over too many lines, it's the other way round.

### `printIn` instead of `println`

The last letters are a lower-case **L** and an **n**: `println`. In some fonts a capital I looks almost the same, but Java sees a completely different name.

## Version notes

Writing a program as just `void main() { … }` and printing with `IO.println` needs **Java 25** or newer. Most Java code you'll find elsewhere, including older tutorials and almost every existing project, uses a longer form that does exactly the same thing:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, world!");
    }
}
```

All the extra words have a purpose, and you'll learn each of them in Stage 2. For now, when you see `System.out.println`, read it as `IO.println`.
